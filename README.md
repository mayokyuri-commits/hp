# Lumire — Web制作会社 コーポレートサイト

ホームページ制作会社「Lumire（ルミア）」の自社PR用コーポレートサイトです。
モダンでおしゃれなデザインを、依存ライブラリなしの素のHTML / CSS / JavaScript で構築しています。

## 特長

- 🎨 モダンなダーク基調 × グラデーション。グラスモーフィズムや浮遊するオーブで先進的な印象に
- ✨ スクロール連動のフェードイン、数値カウントアップ、マーキーなどのアニメーション
- 📱 スマホ・タブレット・PCに対応した完全レスポンシブ（ハンバーガーメニュー付き）
- ♿ `prefers-reduced-motion` 対応、セマンティックなマークアップ、OGP/メタ情報設定済み
- ⚡ ビルド不要。ファイルを開くだけで動作（軽量・高速）

## セクション構成

1. ヒーロー（キャッチコピー・実績数値）
2. サービス紹介（HP制作 / LP / EC / 運用・SEO）
3. 選ばれる理由
4. 制作実績（Works）
5. 制作の流れ（Flow）
6. 料金プラン（Pricing）
7. 会社概要（About）
8. お問い合わせフォーム（Contact）

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | ページ本体・コンテンツ |
| `styles.css` | デザイン・レスポンシブ・アニメーション |
| `script.js` | スクロール演出・カウンター・メニュー・フォーム |

## 使い方 / プレビュー

そのままブラウザで `index.html` を開けば表示されます。ローカルサーバーで確認する場合:

```bash
# Python が入っていれば
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## カスタマイズの目安

- **会社名・連絡先**: `index.html` 内の「Lumire」「contact@lumire.example」などを実際の情報に置き換えてください。
- **配色**: `styles.css` 冒頭の `:root` にあるカラー変数（`--brand` ほか）を変更すると全体の色味が変わります。
- **実績・料金**: 各セクションのテキストを自社の内容に合わせて編集してください。
- **お問い合わせフォーム**: 現在はフロント側のデモ動作です。実運用ではフォーム送信先（メール送信 / フォームサービス等）の設定が必要です。
